# CrazyRouter 独立接入方案与研究依据

研究/实施日期：2026-10-30，北京时间。公开数据链现已正式接入，首次真实结果和运行命令见 [运行说明](crazyrouter-collection.md)。不操作浏览器，不调用收费模型推理接口，不改现有卡片样式。

公开前端实际调用 `/api/pricing`、`/api/status`、`/api/perf-metrics/summary`、`/api/perf-metrics`。研究只读取公开响应及当前资源，不尝试账户、管理、支付或私有日志接口。

**接口优先级：** 实际定价/性能JSON → 当前前端计费公式 → 当前官网文档 → 静态型号/宣传页。首页“600+”不是当前可采公共报价数量；本轮定价JSON与状态页型号范围均为168。

## 2. 定价必须独立解析

`crazyrouter_v1` 不复用 PackyAPI 的采集器和价格假设。复用现有HTTP传输、SQLite事务、Worker租约和读侧快照；整数小数乘法作为通用工具复用。CrazyRouter专用表达式语法独立解析。

### 公共分组与折扣

- 当前只有 `default` 一个已公开分组，`group_ratio.default=1`，168条型号—分组报价。
- 每型号保留 `discount / group_discounts`，按选定分组取对应折扣。站方的0.65表示6.5折，不是减65%。
- 普通Token输入价=`model_ratio × 2 × group_ratio × group_discount`；输出再用 `completion_ratio`。模型输入/输出/缓存必须取同一分组。
- 缓存读遵守 `cache_ratio_configured`，缓存写遵守 `cache_creation_priced`，未明确计价的字段保持null；零与缺失不混用。
- 公开配置本轮为美元额度、`price=7 / usd_exchange_rate=7 / stripe_unit_price=7`。分开保存支付参考字段；不推导“¥1=$1”，不把充值赠送算进全部模型的折扣。
- 折扣标签沿用现有组件，来源为站方披露；不再次扣减已计算的价格。某型号没有可靠折扣/可比基准时，不硬填优惠。

### 28个表达式型号

`billing_expr` 优先于普通比例字段；例如 `gpt-5.6-sol` 基础首档输入4，应用0.65后为2.6，而不是拿普通字段算出另一种价格。

受限语法只接受本轮证实的 `tier / len <= / param("enable_thinking") == true / + / * / 三元分支`，以及明确的Token变量。禁止 `eval / Function` 执行远端表达式。未知语法隔离该型号价格，保留型号、原始规则和错误，不回退到可能错误的普通倍率公式。

- `len`门槛按每型号原文保留；Qwen有256000、32000/128000，不能统一写成272000。
- 命中档位替代基础费率，不分段累加，不把折扣再乘两遍。
- 思考开/关分别保存条件和档位；默认展示思考关闭的首档，规则中展示开启时的价格，不猜测所有请求的参数。
- `cc / cc1h / cc12h`分别保存；`gpt-6.1-terra`的12小时缓存价不能冒充1小时。
- 音频输入变量 `ai` 保留收费项目，不压缩掉多模态附加项。

### 4个峰谷型号

DeepSeek公开 `time_pricing` 带北京时间窗口与高峰/非高峰输入、输出、缓存读价。本轮窗口为09:00–12:00、14:00–18:00，没有周末排除条件。

保存原始窗口与两个档位；在快照导出/页面数据投影时按当前北京时间重算，不等6小时重新采价，也不沿用源缓存中的 `current_tier` 到下个时段。保留源当前档位作证据，不反过来否决本地精确窗口计算。

## 3. 42套媒体矩阵、416条规则

必须保存整套 `image_pricing / video_pricing`，包括源profile、原始绑定型号、平台基础价、官方参考价、能力桶、分辨率、音频、输入视频、参考图数量、格式、验证状态和说明。

- 数值以 **`platform_base_price`** 为准，再乘本组倍率和站方折扣。不要用 `official_price_usd` 替代平台实价，也不从旧汇率反推；例如Seedance2.5存在平台覆盖价，与官方参考换算不同。
- 图片按返回图片计费；附加输入图规则独立保存，不混进输出图片最低/最高价。
- 视频分别存在按秒、按输出Token、按次规则。按百万输出Token的价格不得写成每秒；按次不转换成固定秒数。
- 同组媒体混合单位时不把数字合成一个虚假区间；沿用既有两行报价区和共享详情提示，跨单位显示“按模型规格”，逐模型给出真实单位和完整规则。
- `doubao-seedream-5-0-lite` 与 `hailuo-h3` 的规则绑定到profile声明的原始上游型号。按**响应中显式profile关系**关联，不靠名称相似猜测；本站原始型号身份不改名。
- `wan3.0-video / wan3.0-video-prime` 顶层标签为按次，profile和规则却明确按秒，且没有按次SKU。按明确的按秒矩阵处理，保留两条 `billing_profile_mismatch` 告警和原文；未来出现无法判定的冲突则隔离价格。
- `verification_status=beta` 是站方验证状态，不是本站独立证明。保留并在完整规格中说明，不改造成“已验证稳定”。

## 4. 监测口径与十五日历史

### 来源选择

正式使用逐型号 `/api/perf-metrics` 的 `avg_tps`。状态页另有整体 `tps_24h` 和RPM/TPM，含义与量级不同，不将其直接写成模型输出速度。24小时摘要也不复制成小时原点。

每条原点只含小时均值/成功率，没有该小时请求总数，因此站点、分组和跨时间采用现有**型号/分组/小时等权指数**，不宣称为流量加权SLA。

### 持续保存

- 源实际最多返回7日小时序列；完整拉取168型号，一开始没有流量的型号也登记，后续有流量可自动补入。
- 数据身份为 `station + raw_model + group_key + bucket_at`，保存平均TTFT毫秒、平均耗时毫秒、成功率、输出吞吐t/s、源URL和采集时间。
- 360小时查询窗口在本站积累；源原点按同一身份幂等更新，缺失小时保持缺失，不能把一条摘要复制360次。
- 当前小时允许修订；完整历史不被后续部分小时降级覆盖。接口没有源生成时间，明确保存采集时间，不编造source_generated_at。
- `100% + 全零耗时/吞吐`不能证明有流量，按无数据；明确失败即使耗时0仍保留。
- 十五日60条细条继续每条6小时；数字、耗时和色条按同一时间格聚合，实际覆盖不足15日保持灰色缺口。
- 直接分组数据优先；不把站点总率套入全部分组，不按平台猜型号映射。

## 5. 入库与更新

复用 `transit_stations / transit_groups / transit_offers / transit_offer_observations / transit_performance_observations / transit_source_snapshots / transit_collection_runs` 及两张公共调度表。

新增四张专用表：

| 表 | 内容 |
| --- | --- |
| `transit_crazyrouter_catalog_versions` | 完整目录、计费规则、分布、解析版本、原始响应hash，首次/最后观测 |
| `transit_crazyrouter_metadata_versions` | 白名单公开支付参考配置版本及原始响应hash |
| `transit_crazyrouter_metric_subjects` | 型号/分组成员、活跃状态、近期流量、到期时间、失败退避，进程重启不丢队列 |
| `transit_crazyrouter_metric_summaries` | 24小时源摘要及独立窗口/采集时间，不混入小时事实表 |

源JSON每次型号及协议集合排列顺序可能不同。业务目录按原始型号/厂商ID和集合规范排序后计算版本hash，避免把随机重排当作更新；原始响应仍原样归档。本轮另见少量型号的可选 `release_date / series` 在不同响应中有无变化，属于目录元数据差异，保留不同版本，不将目录版本数直接称为价格变更次数，也不以这些摇摆字段覆盖已核实的官方型号发布时间。

- 报价/公开配置6小时；活跃型号性能1小时，无近期流量型号6小时；Logo每日核对。
- 所有任务走现有常驻Worker，独立价格/性能租约，共用站点互斥，`--force`也不能抢他人有效租约。
- 串行请求、350ms最小请求间隔、20秒超时、8MiB响应上限、180秒单轮预算，超预算留队列下次补采，不并发轰炸。
- 连续3次同形失败停止本轮型号扩散；401/403/429直接停、尊重Retry-After。按型号保存失败与下次补采，不因个别错误抹掉历史。
- 定价原子替换前校验最低规模、已有规模缩减阈值、四大平台族、重复型号、分组引用与数字类型；失败保留完整last-good，不清库。
- 原始响应gzip/hash去重。价格与支付版本的原始证据长期保留，其他传输副本保留7日；监测原点/摘要35日，报价变化版本长期留存。清理严格限制本站归档目录。
- 网站只读原子快照，不在页面请求中联网；复用现有样式、图标、组件、分页和共享悬浮窗。

## 6. 已落地的验证

首次真实正式采集：168型号/报价、1公开分组、416媒体规则、28表达式、4峰谷；172次受限串行请求，全部168型号主体已完成请求，保存6987条小时记录，无型号采集失败。数据含无请求占位，不把原始记录数当成功探测数。

独立测试覆盖语法隔离、12小时缓存、思考档位、别名绑定、单位冲突、折扣不重乘、完整性、空流量、分组身份、当前小时、幂等入库、进程重启、到期跳过、有效租约、失败保留与限流停止。与既有接入及倍率格式化回归一起运行，当前75项通过。

临时样本、备份和测试在项目忽略目录 `work/crazyrouter-*`；生产实现位于 `collectors/transit/crazyrouter*.mjs`、`src/lib/transit/crazyrouter-pricing.mjs` 和 `config/transit/crazyrouter.json`。不提交数据库、快照、原始响应、测试输出或环境凭据。
