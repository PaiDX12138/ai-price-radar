# SudoCode 独立接入方案与证据

2026-10-30核实并实现 `sudocode_v1`。复用项目的存储、调度和展示契约，不复用其他站点的价格公式或监测身份映射。只请求公开资源，不使用登录态，不调用收费模型；没有浏览器操作。

## 获取需要的信息

| 入口 | 获取方式 | 已核实内容与用途 |
| --- | --- | --- |
| [公开报价](https://sudocode.us/api/pricing) | 无鉴权JSON接口 | 全量型号、供应商、真实分组、分组率、缓存率、图片计费、动态Token档、按秒规则、协议、版本与分组关系 |
| [站点配置](https://sudocode.us/api/status) | 无鉴权JSON接口 | 官方Logo地址、名称、额度显示单位、支付参考配置、文档及API入口 |
| [站点公告](https://sudocode.us/api/notice) | 无鉴权JSON接口 | 网站访问区域、支付等来源声明，保存原文，不当作实测指标 |
| [十五日性能](https://sudocode.us/api/perf-metrics/summary?hours=360) | 无鉴权JSON接口 | 型号—版本—小时：成功率、首Token、响应耗时、输出t/s、popularity |
| [官网](https://sudocode.us/) | HTTP读取SPA入口及其当前脚本 | 发现当期价格公式与归一化常量；不执行下载的JavaScript |
| [文档首页](https://docs.sudocode.us/) | 研究阶段读取公开页面 | 补充产品说明；不作为每轮价格的必需依赖或监测数据源 |

**页面接口与公共接口在本站是同一组无鉴权请求，不需要DOM采集或浏览器常驻。** 价格计算需要阅读当前前端脚本，模型和监测数据本身均直接来自JSON。没有猜测私有API或将公开模型列表误称为个人令牌可用列表。

## 库存与字段覆盖

首次真实采集包含77个原始型号、34个分组定义、28个有报价的分组、279条型号—分组报价、9个供应商及11个版本定义。6个空分组定义仍入库为inactive，不产生空卡片。

- 原始 `quota_type=0` 有69个型号，其中 `seed-audio-1.0` 实际被按秒规则覆盖；不能全当Token模型。
- 8个原始 `quota_type=1` 型号按次计费；只标“次”，不凭空承诺每次返回一张图片。
- Token图片的文本输入、文本输出、图片输入、图片输出、缓存价格分别保存。
- 缓存读、短缓存写、1小时缓存写分别保存；缺失/`null` 不填0，明确配置0才保留0。
- 13个型号有动态Token档；按分组条件匹配后，30条报价适用阶梯。
- 按秒音频保留单次最大时长及原始配置，不误放到视频分类。
- 分组、型号、端点类型、版本关系及完整原始规则保存在报价版本中；型号名不改写或归并。

## 单独还原价格，避免倍率错算

研究时当前脚本为官网HTML引用的 `/assets/index-B3eI9iZG.js`，SHA-256：

```text
2c598409d32521271e62a909aa4a60f72660ef32f1aab780c9e913dc1fd32c23
```

脚本实际常量 `Ri=6.89`，并有以下计算路径：

```text
归一化分组倍率 = group_ratio / 6.89
输入 / 百万Token = model_ratio × 2 × 归一化分组倍率
输出 / 百万Token = 输入价 × completion_ratio
缓存 / 百万Token = 输入价 × 对应缓存系数
按次价 = model_price × 归一化分组倍率
按秒价 = rate_per_second × 归一化分组倍率
站方基准折扣 = 归一化分组倍率
```

实现不将6.89永久硬编码为公式：每次报价采集先读取官网当前脚本，静态匹配输入、输出、按次公式，确认其引用同一个唯一数值常量。公式或常量结构无法核实时，本轮拒绝替换报价并保留last-good，等待人工适配；不执行脚本或猜价格。

`/api/status` 的 `price=6.68`、`usd_exchange_rate=6.68`、`stripe_unit_price=1` 是另一套支付/显示配置，**不能替代6.89，也不能证明“¥1=$1”**。保存为公开配置参考，页面继续使用已有“USD额度”标签，不伪造现金充值比例。

本站无逐报价显式折扣字段时，使用已核实的站方公式计算；折扣来源为 `station_formula`、对比基准为 `station_reference`，保留分组、常量、脚本URL、hash及采集时间。它不是独立核实的原厂现金折扣。倍率大于等于1不显示优惠标签。

高Token档的 `input_ratio/output_ratio/cache_read_ratio/cache_write_ratio` **均相对基础输入价**，不是分别对当前输出价、缓存价再乘。`full + input + total_input` 表示含缓存的总输入Token判档，超阈值后整次请求替换价；分组不在适用名单时不套阶梯。源未明确给出的高档1小时缓存系数不自行推算。

## 十五日监测的范围与计算

`hours=360` 已核实返回十五日小时序列；不同于只返回24小时或7日的站点。首次保存23,168条型号—版本—小时事实，涉及71个型号、8个有记录版本，最早北京时间2026-10-15 17:00，最新2026-10-30 16:00。实际数量以后续响应为准。

**接口的 `group=dev/pro/special…` 是版本，不是 `vip gpt/vip gpt pro…` 真实分组。**

1. 原点写入独立版本事实表，绝不将同一个版本序列复制成多条渠道观测。
2. 模型：只纳入当前有效报价、版本关系能够证明的型号—版本组合；同小时版本等权，再按小时平均。
3. 整站：先同小时每型号内版本等权，再型号等权，最后有效小时等权。不是按请求量加权SLA。
4. 真实分组：使用官网 `tier_groups` 映射，限定当前组内型号和所属版本，读侧生成“组内型号综合”；标记 `aggregation.kind=group_models` 和 `sourceVersion`，说明非渠道独立实测。
5. 已映射版本没有记录时不借其他版本填充；例如特供3蒸馏版目前仍保留暂无记录。`svip` 无明确版本归属，只能使用现有组员模型综合回退，并明确为系统汇总。
6. 已移除的型号或不属于当前版本的历史数据保留原点，但不进入当前站点指数。`popularity` 不冒充请求数，不作为成功率权重。

可用率、TTFT、耗时、t/s 共用UTC整点360小时网格，展示北京时间；60根细条各对应固定6小时。缺小时不压缩、不补成功；主值只平均有记录小时。当前未结束小时标partial，后续完整小时可覆盖，旧快照不得回滚新事实。0%失败保留；无流量、全零时延的100%占位不当成功样本。

没有公开监测的6个当前型号继续为空：`gemini-2.5-flash`、`gemini-2.5-flash-image`、`gemini-3-pro-image-preview`、`gemini-3.1-flash-lite-image`、`gemini-3.5-flash-lite`、`gemini-3.7-flash`。不套用同平台其他型号指标。

## 保存规范

| 表/工件 | 用途与身份 |
| --- | --- |
| `transit_stations/groups/offers` | 当前站点、真实分组、型号—分组报价，使用既有唯一键及不可变报价观测 |
| `transit_sudocode_catalog_versions` | 完整目录、规则、版本关系、库存、解析版本及对应前端政策hash；内容版本去重 |
| `transit_sudocode_metadata_versions` | 白名单配置、公告、来源hash；内容变化才新增版本 |
| `transit_sudocode_tier_hourly` | 主键为站点+原始型号+版本+UTC小时；保存源快照时间、指标、partial、popularity、映射状态和响应hash |
| `transit_source_snapshots` + `data/transit/raw/sudocode/*.gz` | JSON/HTML/JS/Logo按hash归档，数据库不重复保存大脚本文本 |
| `data/transit/latest.json` | 全站一次性原子导出；保留其他站点，前台不请求外站、不读SQLite |

小时事实保留35日，覆盖15日展示和恢复余量；原始传输副本7日，已接受目录、公式、配置、公告引用原文保留。不在入库时裁剪小数，两位小数仅在既有紧凑卡片展示层处理。新增表为幂等、追加式迁移，不重置数据库。

## 定时与失败处理

现有Worker自动发现 `config/transit/sudocode.json`，无需另加cron：报价/目录/脚本/公告6小时，性能1小时，Logo每日复核；强制采集可提前复核Logo。价格和性能分别保存next-due、租约及失败状态，重启不丢队列。

每轮串行限速350ms、20秒单请求、120秒预算、JSON/脚本16MiB上限、Logo1MiB上限。监测仅需1次汇总GET，不按型号反复请求。快照超过2小时、公式未知、缺核心家族、型号/分组/报价明显缩水或响应无效均不清空现存数据。401/403/429停止本轮后续外站请求；指数退避并尊重Retry-After。单站失败不影响其他站点导出。

站方公告声明官网改为面向海外访问，服务器地域/DNS/网络失败需要从实际出口排查。配置发现的加速/直连域名仅保存来源说明，未经验证不自动切换；不硬编码临时IP、不关闭TLS校验。
