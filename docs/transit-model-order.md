# 中转站模型排序与自动更新

## 显示规则

- 首页只有明确点选「图片生成 / 视频生成」Tab 才展示该类模型。全部、普通平台、搜索均不能绕过此限制；同一张价格表不会混用 Token 和图片/视频单位。媒体专属站点在普通 Tab 不显示空卡片。
- 默认代表模型优先 Claude、GPT、DeepSeek、Gemini，再考虑 Grok、GLM、Kimi、Qwen 和其他厂商。每个平台先取一条；缺少某个平台时顺延其他实际存在的模型，绝不展示不存在型号或虚构报价。首页仍最多四行。
- 单平台内部及详情分组：各系列先选最新实际可用代表，再展示该系列旧款，避免旧日期版占满前四行。代表按已停用状态、主代际、产品定位层级、次版本、已知发布日期、名称自然顺序稳定排序。新主代际优先于上一代。搜索命中优先；详情仅排序当前分组实际支持的模型，保留 `+N`、分页、卡片样式和监控数据。
- 产品定位使用通用系列规则（例如同主代际 Opus 在 Sonnet/Haiku 前，GPT Astra 在 Sol/Terra 前，Pro 在 Flash 前），不是固定型号名单。这是展示策略，不是根据模型名称宣称已经实测出能力榜单。
- 最新型号不在该站/分组时，自动跳过，只展示其实际支持的下一个型号。新模型入库后即参与规则，不需要手动追加型号。

## 自动模型资料

公开来源：[Models.dev API](https://models.dev/api.json)，[字段说明](https://github.com/anomalyco/models.dev)。这是社区模型资料库，并非各厂商官方接口或能力排行榜。

`collectors/transit/model-catalog.mjs` 每 6 小时同步直接厂商目录（不采用第三方中转提供商别名），保存系列、发布日期、规范模型标识、停用状态、输出类型及来源链接。只做精确型号匹配；不模糊猜测某个站点别名对应哪个官方型号。规范标识可用于识别来源明确的版本别名。年月精度保留原值，不把型号日期、首次采集时间当发布日期。

- 落盘：`data/transit/model-catalog.json`，原子替换；保留 `.last-good`。
- 调度：既有 `pnpm worker` 会调用 `scripts/collect-transit.mjs --due`，模型资料使用独立持久化 6 小时到期检查。
- 请求：一次公开目录请求，15 秒超时、12 MiB 限额；缺少关键厂商/目录异常不替换有效数据。
- 失败：状态保存在 `.state`；15 分钟起退避，最多 6 小时，worker 后续 tick 到期自动回扫；使用跨进程锁及超时锁回收。资料失败不阻止站点价格采集。
- 前台：仅本地 JSON + 30 秒内存缓存，不访问外网或数据库，不需要重新构建前端。只向浏览器传该站实际型号的资料，避免发送整个目录。
- 无资料型号：保留原名，通过版本数字及通用系列定位兜底；不冒充已核实发布日期或实测能力。

手动立即同步：`pnpm collect:transit-models`；只检查到期：`pnpm collect:transit-models -- --due`。

核对范围：首页全部/四个平台顺序、单平台、新型号自动前移、缺失型号顺延、普通搜索排除媒体、媒体 Tab、详情 `+N` 展开和原分页。
