# 中转站图片 / 视频卡片定价

## Packy 公开来源（2026-10-28）

- 定价接口：https://www.packyapi.ai/api/pricing
- 图片说明：https://docs.packyapi.ai/docs/paint/GPTImage.html
- 分组说明：https://docs.packyapi.ai/docs/token/2-group.html
- 官网价格页：https://www.packyapi.ai/pricing

接口提供 `model_price_min/max`、基础 `model_price`、`image_billing`、分组倍率及模型分组倍率覆盖。原始字段与应用分组后的价格区间已由现有采集器保存，不需要页面刷新时再请求官网。

`gpt-image-2.5-flare/sunburst` 明确返回 `image_billing: token`，不能宣称固定按次价；图片说明的质量、尺寸会影响生成规格，接口区间不是某个具体规格的保证报价。MiniMax-H3 系列有视频价格区间，但当前资料没有确认完整的时长 / 分辨率价格矩阵。

官网公开前端还引用图片规格示例接口 `/api/option/image_pricing_examples`，一次请求返回 403，未重复请求、未接入定时采集；没有用猜测值补全规格价。公开前端的 `image_billing` 模式包括 `token`、`per_image`、`upstream_cost`。

## 显示规则

- 仅图片 / 视频卡片模型区走独立两列表格：模型、站点报价。外框、头部标签、监测区、更新行不变。
- 保留原有 128px 区域、25px 行高、最多四条模型和已有模型排序；价格和单位保持单行，禁止长单位撑出模型区。
- 优先展示同一个报价分组的有效 min/max 区间；不同分组之间不拼接范围。组内倍率已由采集器计入，不再重复乘。
- 同模型多组时选择有价格证据且起价最低的分组，折扣、范围、分组名称保持一致；这不是所有规格均最低的承诺。
- 模型列占 60%，价格列占 40%；长模型名允许最多两行，行内保持紧凑行高，不撑大原有模型区。折扣标签保留。
- 图片单位 `/张`，视频 `/次`。直接显示站点接口提供的价格区间，不加约等于符号；悬浮明确实际按 Token、输入另计。所有范围均不伪装成某规格固定价。
- 单边范围显示“起”或“≤”；无区间才回退明确固定价；未知显示“未披露”。无效、负数、倒置范围不拿来报价。
- 复用现有自定义 Tooltip 展示完整模型名、价格、计费方式、分组和额度口径。不输出冗长单位，不新增媒体倍率列。

## 详情页分组报价与对齐

- 本地存档已经保存 6 个媒体模型的分组价格区间。原详情映射只暴露 `fixed_price`；这些模型的固定价为空，所以详情误显示“—”，不是缺少已存的区间数据。
- `TransitQuote.mediaPricing` 现逐条映射所属分组的 min/max、固定价、计费方式。分组卡片不引用首页最低价分组，也不对已计入倍率的价格再乘倍率。
- 价格块按图片 / 视频显示本组已披露的报价区间及 `/张`、`/次`，第二行显示计费方式。信息图标悬浮列出各模型完整价格和计费口径；缺失报价不补零，不混入其他分组。
- 当前存档中的区间：`grok-officially` 图片 `$0.1–0.2/张`；`image` 图片 `$0.0294–3.55785/张`；`video` 视频 `$1.485–22.995/次`。均为存档报价，不代表本次实时重新采集；完整规格价仍没有证据，不填猜测值。
- 文本与媒体价格块统一为 56px 两行区域；内容区用 flex 将监测区和更新时间作为底部对齐块，保留原有颜色、细条及卡片正常内边距，不加固定整卡最小高度。
- 展示金额统一去除浮点尾数，保留最多六位常用小数；极小非零值不舍入成零。首页与详情媒体报价共用格式化函数。
