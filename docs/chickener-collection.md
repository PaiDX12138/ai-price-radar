# 鸡哥AI：正式接入与运行

2026-11-02接入，独立采集器 `chickener_v1`，配置 `config/transit/chickener.json`。沿用现有页面，不增加卡片样式或浏览器采集；研究及计费口径见[接入方案](chickener-integration-plan.md)。

## 数据与规则

- 当前公开目录21型号、9个有报价组、42条报价，19文本/2图片按次。报价来自匿名`/api/pricing`，元信息来自`/api/status`。
- 15条动态表达式通过独立白名单AST解析：长度阶梯、普通/priority/fast、工作日峰谷、基础缓存写和1h缓存写。与普通倍率矛盾时以表达式为准，不执行下载的JS，不识别的表达式隔离为未知价。
- 当前数据的DeepSeek按北京时间工作日09:00–12:00、14:00–18:00峰时2倍。保存原规则，快照导出及服务端视图本地重新计算当前价，不改变采集时间、不等待6小时网络抓取。现有网页已打开后不会凭空获得推送，重新导航/读取后获得当前投影。
- 名义币种为站内CNY Credits。`price=1`不是已核实充值订单，充值倍率为空；不显示“¥1=$1”，也不把兑换加赠或组倍率冒充官方折扣。不同币种/缓存TTL/服务等级没有同口径参考时，不编造折扣标签。
- 图片按`model_price × 组倍率`、以“次”为单位。2个图片型号在生图组为0.1/次，default为0.4/次；不擅自改成张/秒。
- TTFT、总耗时、成功率、TPS来自`/api/perf-metrics?model=...&hours=360`。使用当前报价成员身份过滤；非当前成员仍在源响应中保留，摘要独有型号不生成在售报价。缺小时不补0/100，不从另一真实分组复制指标。
- `cc`保留基础缓存写，未明确TTL不写成5分钟；`cc1h`单列。DeepSeek端点描述与通用协议声明冲突作为信息告警保存，不代表采集失败或实际模型调用已通过。

## 自动调度

现有`pnpm worker`已分发该站；无须新增cron，生产已有`quote-worker`时不另开重复服务。

| 阶段 | 频率 | 保障 |
|---|---|---|
| 价格/公开元信息 | 默认6小时 | 完整性/缩减校验，事务写入，错误保留last-good |
| 性能 | 独立1小时 | 21型号串行，250ms间隔、20s单请求、120s预算，持久化续采 |
| Logo | 每日/缺失/手动强制 | 校验PNG签名与尺寸，成功后原子替换本地图片 |
| Worker | 常驻30秒或通用Worker60秒轮询 | 心跳、租约、超时、失败退避，重启不丢队列 |

价格失败仍可以上次目录采性能；三次连续请求失败结束本轮，未采型号下轮优先；401/403/429停止并遵守冷却。历史小时保留35日，页面滚动15日、60根固定6小时细条。未取得请求量分母，只能显示模型/组/小时等权统计，不宣称请求量加权SLA。

## 存储

新增公开目录版本表`transit_chickener_catalog_versions`、公开元信息/独立摘要版本表`transit_chickener_metadata_versions`，按内容hash去重；型号任务表`transit_chickener_metric_subjects`保存next-due、last-success与退避。

当前价、报价观测、收费项目、原始快照及性能小时复用公共表。时间规则同时保存原始表达式和解析投影；收费项同时保存基础单价、组倍率及有效单价。源时间、规则更新时间和打包时间分开。

公共基线导出仅含前两张公开版本表，不含队列、心跳、运行错误或原始传输目录。旧版本基线缺少新增表时按空表兼容；新包校验、事务导入、去重及保留服务器较新事实仍沿用原合同；导入不额外创建备份副本。

## 实际验证

- 本机首次真实采集：21型号、42报价、2,441条当前成员小时写入；21个型号请求均成功。与研究时2,434条可投影记录相比，源站新增小时造成数量变化，未强制改回旧数。
- 后续price-only真实更新验证价格独立调度；目录、收费项、PNG和正式快照均已落盘。原始响应归档，不把小时改成采集时间。
- 覆盖表达式阈值/峰谷边界、合法零与未知缓存、目录关系、85条研究时非当前成员记录隔离、重复采集、续采、价格失败性能继续、旧基线与停用恢复等测试。
- 生产构建与HTTP检查：列表/图片筛选/详情/Claude筛选/图片详情、Logo及公开诊断API正常；没有操作浏览器。Zeta详情返回Next的not-found内容，流式请求可能HTTP200，不等于仍存在站点数据。
- 本机常驻中转Worker已启动，心跳可见；鸡哥21型号任务成功，下一小时持久化到期。不能把本机运行等同于线上已部署。

## ZetaAPI停用

维护者已明确要求移除，`config/transit/zetaapi.json`设为`enabled=false,status=paused`。不再每日复核，旧的停服自动每日检查记录仅属历史。

- Worker不创建该站actor；迁移/快照导出/Worker轮询删除其价格与性能调度行，数据库站点状态暂停。
- 公开查询与快照读取按本地配置排除停用站，即使读取旧JSON或损坏后回退last-good，也不显示Zeta。旧公开基线导入不能重新发布它。
- 历史报价、监测和审计记录不删除；公开导出只带当前发布站，未清空服务器已有历史。
- 停用依赖的配置文件已加入Next运行文件追踪，部署时仍需保留仓库`config/transit/`目录。

## 运行命令

```bash
pnpm transit:migrate
pnpm collect:transit -- --station=chickener
pnpm transit:status
```

正常服务使用既有`pnpm worker`；只运行中转可选`pnpm worker:transit`。`--due`遵循到期时间，手工不带`--due`仍尊重活跃租约。不要为“填满细条”伪造历史或删除正式数据库。
