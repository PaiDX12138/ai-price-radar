# 中转详情分组分页

## 更新链路

- 每页仍为 12 个分组，保留原分页样式、筛选条件和 URL。
- 分页只对已经加载的分组做客户端切片；不请求数据库、采集接口或整页 RSC。
- `useTransitPageSearch` 使用 URL 外部存储订阅：点击后同步通知页码与列表，不等路由 transition 更新 `useSearchParams`。浏览器前进 / 后退监听 `popstate`，URL 仍是唯一页码来源。
- 常规点击拦截默认导航；Ctrl / Command / Shift 点击保留浏览器原行为。

## 移除的开销

- 细条每次格式化不再逐根创建多个 `Intl.DateTimeFormat`，统一复用三个北京时间格式化器。
- 细条分桶和时间标签使用 `useMemo`；移动键盘焦点不再重新分桶、格式化全部标签。
- 筛选结果、分组索引使用 `useMemo`，单遍建立分组，不再为每个分组重复扫描全部报价。
- 模型检测区和分组卡片使用 `memo`，只翻分组页码时不重复渲染无关的检测卡片。

## 保持滚动位置

- 删除翻页后的标题 `focus` / `scrollIntoView`。
- 点击前记录当前滚动坐标，并临时保留分组网格高度，避免最后一页分组少导致页面收缩、分页控件上移或滚动被截断。
- 网格 `content-start`：保留的是列表区域高度，不拉高单张卡片，不填充假卡片。
- 提交后在 layout effect 中仅在坐标变化时无动画恢复原坐标。
- 筛选条件 / 数据集变化和窗口尺寸变化时解除网格高度保留，重新按内容、响应式列数布局。
